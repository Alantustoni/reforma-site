DESCRIÇÃO DA ATIVIDADE
O ReForma é um site de doação de sobras utilizáveis de materiais de construção. O objetivo é conectar doadores e interessados para incentivar o reaproveitamento, reduzir desperdícios e apoiar melhorias de moradia. A retirada seria combinada diretamente entre as partes.

O site possui dez páginas HTML interligadas, CSS responsivo, recursos de acessibilidade, catálogo demonstrativo, imagens com fontes, vídeo com legendas, áudio com transcrição, iframe e documentação. Na versão final, o formulário de contato é validado em JavaScript e guarda um rascunho no localStorage.

Os anúncios, as iniciativas e os indicadores exibidos são fictícios. Os formulários geram demonstrações locais, sem enviar mensagens ou publicar doações. Os RAs dos integrantes são informados apenas no envio pelo Blackboard.
